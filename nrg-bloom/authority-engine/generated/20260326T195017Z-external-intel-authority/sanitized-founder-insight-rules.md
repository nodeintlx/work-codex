# Sanitized Founder Insight Rules

Founder insight still matters, but it should be abstracted away from live-sensitive facts.

- Talk about operating principles, not confidential counterparties.
- Translate field experience into lessons about logistics, uptime, remote execution, and trust.
- Avoid describing active disputes, live negotiations, or partner-sensitive specifics.
- Sound like an operator interpreting the market, not a victim narrating constraints.
